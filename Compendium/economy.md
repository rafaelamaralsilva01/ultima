# Economia — de onde vem gold, onde gastar

Fontes: [UO Outlands Guide 2026 — cap. 3 e 4](https://hardlygospel.github.io/uo-outlands-2026-guide/). Números de gold/hora abaixo são estimativa de guia genérico, não confirmado 1:1 pra Outlands — usar como ordem de grandeza, não meta fixa.

## Estrutura do mercado

- **Auction House**: mercado secundário principal pra item raro.
- **Player Vending**: casa com NPC vendor estocado — gera gold passivo vendendo craft/consumível.
- **Bulk Order Deeds**: NPC crafter pede lote de item, paga bem + reward — bom pra warm-up de Blacksmith novo (nosso build de suporte).

## Tiers de item no mercado

| Tier | Exemplo | Demanda |
|---|---|---|
| Consumível de alta demanda | Healing potion, explosion potion, arrow, bandage | Constante, preço moderado |
| Item raro de alto valor | Power Scroll, armadura Exceptional, arma runic | Preço alto, ligado a evento/drop raro |
| Item de evento sazonal | Cosmético de Halloween/Winter/etc | Preço varia muito, época limitada |

## Métodos de renda por fase

| Método | Faixa de gold/hora (estimativa) | Requisito |
|---|---|---|
| Farm de monstro early | 5.000-20.000 | Skill básica, área segura |
| Farm de monstro mid-dungeon | 20.000-60.000 | Skills 70-90, grupo ajuda |
| Farm de monstro endgame | 100.000-500.000+ | Build completa, dungeon de risco |
| Treasure map | 5.000-500.000+ (tier 1 a 6) | Cartography + capacidade de combate pro guardião do baú |
| Bard farming (Provoke) | 50.000-120.000 | Skill de bard, risco pessoal baixo |
| Taming (Greater Dragon) | 200.000-500.000 | Build de tamer completa — não é nosso build, citado só pra referência de teto |
| Crafting/vending | Passivo, variável | Casa com vendor + estoque |

**Pro nosso Blacksmith/Miner**: a fonte de renda principal não é "farmar monstro", é **crafting + bulk order deeds + vending**. Minerar ore é o insumo, craftar em Exceptional é o multiplicador de preço.

## Champion Spawns

Evento de PvE em waves, boss final dropa Power Scroll (50k-2.000.000+ gold de valor). Alto risco de disputa (PvP/guilda) pelo drop — não é conteúdo solo tranquilo, mencionar aqui só por completude (liga com `content-and-risk.md`).

## Onde gastar gold (prioridade sugerida pro início)

1. Bandagem, potion básica, tools de crafting — sempre reabastecer primeiro
2. Runa/runebook marcado — segurança > qualquer upgrade de gear
3. Skill training (NPC trainer, Training Credits) — ver `Builds/`
4. Upgrade de material (ore/board colorido) — só depois que a build de skill já estiver decente
5. Casa — quando já tiver ~50k+ de reserva (referência de guia genérico, não confirmado valor exato pra Outlands)
